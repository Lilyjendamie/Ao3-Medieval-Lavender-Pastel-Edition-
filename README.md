## About this Edition

This repository contains a customized version of the original skin, redesigned with a **soft lavender pastel medieval aesthetic** while preserving the charm and atmosphere of the original theme.

The goal of this edition is **not** to replace the original project, but to offer an alternative color palette for users who prefer a lighter, softer, and more romantic reading experience.

---

# Modifications

- Redesigned the original warm brown palette into soft lavender pastel tones.
- Refined interface colors for improved visual harmony.
- Preserved the vintage paper-inspired aesthetic.
- Updated buttons, links, borders, and UI accents.
- Replaced or recolored selected decorative backgrounds.
- Minor CSS refinements and readability improvements.
- Maintained the medieval-inspired atmosphere of the original skin.
